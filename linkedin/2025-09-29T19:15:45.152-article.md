⬛ Terminal multiplexer like #tmux is a program many junior developer don't know they should at least know about.


ℹ A terminal multiplexer lets you have tabs in a single terminal window. You can attach and detach from it, so programs you started there can continue to run in the background. And you can attach to one session from multiple sources.


👉 If you have a server somewhere in the cloud or the company's datacenter to which you connect over Secure SHell (SSH) where you do long data processing jobs, the easiest way to go about it is to just start the script in tmux and detach the session. This way you can disconnect the connection and the script will continue to run.


👉 You can also share the session with a colleague, she can run tmux attach and will end up in the same session as you. No pixelated and hard to read text on a video call. Also, this works over fairly bandwidth-constrained connections, even 3G somewhere in the woods might work. If it doesn't using regular SSH, try to use mosh for the connection.


👉 You can script the tabs, tab names and rudimentary windowing in a tmux script, so you can launch the whole programming or administrative environment with a single command/ script. This is great if you need to e.g. launch tailwind for the frontend, node.js on the backend, some kind of server or database and even Visual Studio Code or IntelliJ.


😉 This way, you will also document what needs to run if you get a new colleague or tend to forget these things yourself.
