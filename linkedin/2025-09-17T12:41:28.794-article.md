When AI Coding Assistants Cross the Line.

Back in 2024, I was building a driver for a fairly obscure piece of hardware. The vendor guarded its documentation carefully — access required NDAs, approvals, and lawyers. Since I didn’t have that, I fell back on the classic approach: reverse-engineering.
Then I tried GitHub Copilot. To my surprise, it autocompleted not just generic code patterns, but fragments that looked suspiciously like the vendor’s proprietary documentation. Information that should never have been public was suddenly available in my editor. Whether Copilot had absorbed it from training data or from somewhere else didn’t matter — the result was clear: intellectual property was leaking through the tool.
Fast-forward to 2025. I’m now working on an iOS app for bird watching — pure Swift, no JavaScript anywhere. To help with some math problems, I turned to Google’s Gemini CLI coder. That’s when things took a strange turn.
In the middle of a session, my coding context suddenly shifted. Instead of my project, I was looking at completely unrelated Javascript code from someone else’s machine. A bit if digging into the node process memory (gemini runs on node) and I found a bunch of strings that clearly came from a MacBook belonging to somebody named Pankaj.
Think about that for a moment. Proprietary code, user data, and possibly sensitive credentials — all moving through the same black box, with no real filtering or obfuscation of the sensitive data. IfAnd if this kind of data/context mixing can happen inside Google’s infrastructure, what does it mean for everyone else?
For developers and security professionals, the lesson is uncomfortable but necessary: AI coding assistants are not just autocomplete tools. They are shared, cross-connected systems, trained on massive datasets, with poorly understood isolation guarantees. And when isolation fails, the first casualty is security.

We need to ask harder questions of these tools — not just about productivity gains, but about data ownership, leakage, and accountability. And be very careful when sensitive secrets involved.
