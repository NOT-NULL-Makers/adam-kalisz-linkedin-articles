Another Functional JVM and Prague Lambda united meetup, another great evening full of interesting insights about programming, technical and less technical topics.


What I found interesting is we spoke quite a bit about architecture such as the AWS Lambda and Kinesis double sandwich with Michal Janoušek, options for sandboxing of user provided data analysis code around the #JVM with David Lebl and organization of work and people Tomas Morstein.


With Tomas Brejla we spoke about labels in Java code and how the absence of them in #Clojure teaches you to write straightforward code.


There were other topics too, like Elixir and Erlang, DEC/ MUMPS, DTrace, flame or icicle graphs and a lot more.


Thanks to Ondra Pelech for organizing!
