You know it, 2 Factor Authentication is everywhere and it's a pain for backup and development.



Saving a QR code in a password manager is a pain. Also, sometimes you have to have 2FA even for some account which is not relevant for security but it makes sharing the credentials a pain.



That's why you can use https://notnullmakers.com/tools/qr/ which runs in the browser and does not send the “uploaded” anywhere to scan the QR code, verify and copy the One-Time Password generating code. This code can be later inserted and the QR code regenerated.
