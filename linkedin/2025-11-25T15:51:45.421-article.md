🧮 Do you think doing serious number crunching on the Java Virtual Machine and in the programming language #Clojure is a mistake?


Chris Nuernberger and Harold Hausman certainly are among the most qualified in the community to prove you otherwise. Projects such as dtype-next  for contiguous primitive datatype containers allow you to allocate on the jvm heap and working with Java Objects or the native heap, doing mmap, zero-copy work with Python's numpy or Clojure's neanderthal and in general utilize the CPU and memory of the computer much more efficiently.


🛠️ And there is a lot more the team at TechAscent, LLC can do for you. Do you need to bridge from the JVM into Python? libpython-clj is there to help. Do you need efficient JSON or CSV parsing? Try charred. Do you have specific high performance needs for immutable Clojure collections? HAM-fisted can be of help or at least an inspiration.


🫴 Last but not least, these guys are super friendly even by the standards of the Clojure community. I wouldn't be surprised if a tedious number crunching or machine learning job turns into a fun project with them.
